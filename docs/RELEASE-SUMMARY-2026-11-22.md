## 经典版：公开 1.7.2 → 2.2.1

| 版本 | 变化 |
| --- | --- |
| 1.7.3 | 统一首次安装与恢复默认时的玻璃配置，并保留覆盖升级中的已有参数。 |
| 2.0.0 | 加入 Google / 百度联网识图入口、默认引擎与入口开关、服务端共享额度；移除主页点按白圈。 |
| 2.0.1 | 每次新搜索前确认上传及消耗一次共享额度；修复结果图片加载闪动，识图结果接入应用玻璃效果。 |
| 2.0.2 | 改善识图结果卡片的图片填充，去除上下或两侧的灰色补边。 |
| 2.0.3 | 完善结果面板底部入场、全区域下拉与关闭动画；列表先回顶部，再收至半屏，继续下拉关闭。 |
| 2.0.4 | 固定顶部照片缩略图居中，切换 Google / 百度时不再随文字宽度移位。 |
| 2.1.0 | 搜索面板使用引擎图标，识图设置补齐触感和额度条；二级设置直接退出；成功结果按照片内容与引擎保存，重复查看免费，刷新另行确认。 |
| 2.1.1 | 采用 Google、百度原始官方图标，调整可见尺寸，使两枚图标视觉大小接近。 |
| 2.2.0 | 引入按钮 / 上拉面板两套独立玻璃参数；该版曾重制玻璃菜单，不能把这套布局当作最终版。 |
| 2.2.1 | 恢复 2.1.1 的原有上拉菜单布局与原生容器；普通菜单玻璃默认关闭，可选择开启。识图结果保留玻璃，两套参数仍独立保存。 |

## Alpha：公开 1.4.5 → 1.8.2

| 版本 | 变化 |
| --- | --- |
| 1.6.0 | 新增本地自然语言搜图实验：在手机建立照片向量索引，模型就绪后可离线查询。 |
| 1.7.0 | 底部新增搜索 BETA；重做本地搜索页面、相册范围与结果布局；宽图可占整行，模型与索引状态由页面级状态持有。 |
| 1.7.1 | 搜索页接入首页同款上下栏渐变毛玻璃，并修正底部安全区。记录中的 1.7.0 旧真机 CPU 搜索结果不代表后来共享中心已验收。 |
| 1.7.2 | 改为调用独立 Photerest AI Hub，支持迁移已有模型与手动清理旧副本；属于仅构建完成的共享模型实验。经典版尚未接入。 |
| 1.8.0 | 仅 Google 的联网搜图；上传前确认、共享额度条与本地历史免费复用。详情搜索按钮默认毛玻璃 14 dp，可关闭或调节 0–30 dp；取色遵循 Material。新增界面采用 Material 3 Expressive。 |
| 1.8.1 | 修复搜索面板上拉漂移及首次搜索完成后一直加载的问题，无需关闭重进才能显示结果。 |
| 1.8.2 | 修复视频 A 的预览被带到视频 B 的展开封面及留白；增加媒体和视图绑定归属检查，保留进度延续及返回动画。 |
