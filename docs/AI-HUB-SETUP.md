# Photerest AI Hub 0.1.0 安装与迁移（实验）

本中心与 Alpha 共享模型的方案仅构建成功，模型加载、迁移和跨应用效果仍待真机验证。Android 12+ ARM64；中心与 Alpha 必须使用同一签名。本次发布提供匹配签名的安装包。

1. 先安装同一 Alpha 1.8.2 Release 附件中的 Photerest-AI-Hub-0.1.0.apk，再覆盖安装 Alpha 1.8.2；保留已有资料，不先卸载 Alpha。
2. 进入 Alpha「搜索 BETA」，在共享模型中心卡片迁移已有模型，或由中心下载约 485 MB 模型。导入、下载和分析保持前台。
3. 迁移期间旧副本暂时保留，需要额外存储空间。中心校验完成、Alpha 成功调用共享推理后，才手动确认清理旧副本。
4. 先选少量照片建立索引，用自然语言查询。系统回收进程后会重新加载同一模型文件，不代表再次下载。
5. 经典版尚未接入；各客户端的照片范围、资料与向量索引仍独立。不要写成两个正式产品已完成共享模型实测。

本模型中心不包含完整模型；源码采用 Apache-2.0，模型及其运行库各有独立条款。源代码压缩包含 hub/client/lab 独立 Gradle 工程，解压后配置 SDK，用 `gradlew.bat :hub:assembleDebug :client:assembleRelease` 构建；使用与客户端相同证书。
