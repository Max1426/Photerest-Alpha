# AI Hub 0.2.0 安装与共享模型

Android 12+ ARM64；中心与客户端需同签名。附 Hub 0.2.0（2），已加入经典白名单，保留 Alpha/Lab；SDK/AIDL 不变。

1. 覆盖安装同一发布的 Hub 0.2.0，不先卸载，保留已有模型。
2. 覆盖客户端；Alpha 1.10.1 与经典 2.5.0 的新 φ 偏好默认关闭，从设置开启。
3. 已有模型复用，未准备时进入中心下载或导入约 485MB 模型，前台完成并校验；客户端不保存第二份模型。
4. Alpha 有旧私有模型时可用迁移入口，中心校验和共享推理成功后才手动清旧副本；经典版没有该历史副本。
5. 客户端各选照片分析、文字查询，各自保存索引和图库权限。进程回收后重新加载原模型，不等于再次下载。
6. 本地组件安装只选择 APK，无自动下载服务；卸载 Hub 会移除中心及模型并影响其他客户端，需要系统确认。

经典需 Hub >=0.2.0，不能用旧 0.1.0 配套。用户已有经典、Alpha 和 Lab 调用成功反馈，新客户端安装/管理和升级仍待手机验收。模拟器 UI 不是 ARM64 模型验证。

中心源码 Apache-2.0，模型/运行库有独立条款。配置 SDK 后执行 gradlew.bat :hub:assembleDebug :client:assembleRelease；自建客户端和中心使用同一证书。
